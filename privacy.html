Политика конфиденциальности DogLife

Дата вступления в силу: 11 октября 2026 года

1. Общие положения

DogLife — приложение для владельцев собак, предназначенное для ведения профилей питомцев, хранения информации об их здоровье и организации ухода за ними.

Настоящая политика объясняет, какие данные могут обрабатываться при использовании приложения и для каких целей.

2. Данные аккаунта

При регистрации и использовании аккаунта мы можем обрабатывать сведения, необходимые для создания аккаунта, входа в систему и обеспечения работы приложения.

3. Данные питомцев

В зависимости от используемых функций приложение может обрабатывать имя питомца, породу, дату рождения, вес, номер микрочипа, фотографии и другие сведения, которые пользователь добавляет в профиль.

Пользователь самостоятельно отвечает за точность предоставляемой информации.

4. Здоровье и уход

Пользователь может сохранять записи о здоровье питомца, прививках, лекарствах, весе и других аспектах ухода. Эти сведения используются для предоставления соответствующих функций приложения.

DogLife не заменяет консультацию ветеринарного врача.

5. Геолокация

Если пользователь включает функции отслеживания прогулок или другие функции, использующие местоположение, приложение может обрабатывать данные о местоположении для предоставления этих функций.

Пользователь может управлять разрешением на доступ к геолокации в настройках устройства.

6. Хранение данных и сторонние сервисы

DogLife использует локальное хранение данных на устройстве. Для отдельных функций данные питомцев и другие необходимые сведения могут обрабатываться с помощью облачной инфраструктуры Supabase.

Обработка данных зависит от используемых функций и настроек приложения.

7. Передача данных

Мы не продаём персональные данные пользователей. Данные могут обрабатываться поставщиками технических услуг в объёме, необходимом для работы приложения, обеспечения хранения данных и предоставления выбранных пользователем функций.

8. Защита и хранение данных

Мы стремимся применять разумные технические и организационные меры для защиты информации. Данные хранятся столько, сколько необходимо для работы приложения и выполнения соответствующих целей, с учётом применимых требований законодательства.

9. Удаление аккаунта и данных

Пользователь может обратиться с запросом на удаление аккаунта и связанных с ним данных. Запрос должен содержать достаточно информации для определения аккаунта. Некоторые сведения могут сохраняться, если этого требует закон.

10. Конфиденциальность детей

DogLife не предназначен для самостоятельного использования детьми младше возраста, при котором они могут давать согласие на обработку персональных данных согласно применимому законодательству.

11. Изменения политики

Мы можем периодически обновлять эту политику. Актуальная версия будет опубликована на этой странице с указанием даты обновления.

12. Контакты

По вопросам конфиденциальности и обработки данных обращайтесь по контактному адресу разработчика, указанному на странице приложения в App Store.
